# Mini Project Node.js

## Server Informasi Kampus

### Deskripsi

Project ini merupakan server sederhana menggunakan Node.js tanpa framework.

### Fitur

- Halaman Home
- Profil Kampus
- Fakultas
- Program Studi
- Kontak
- Tentang
- Halaman 404

### Menjalankan Program

Install Node.js terlebih dahulu.

Jalankan:

```bash
node server.js
```

atau

```bash
npm start
```

Server berjalan di:

```
http://localhost:3000
```

### Routing

| URL | Keterangan |
|-----|------------|
| / | Home |
| /profil | Profil Kampus |
| /fakultas | Daftar Fakultas |
| /prodi | Program Studi |
| /kontak | Kontak Kampus |
| /tentang | Tentang Website |
| lainnya | 404 Not Found |

### Status Code

- 200 OK
- 404 Not Found
